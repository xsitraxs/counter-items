# Шаблоны для template matching

Агент ищет героев на верхней панели через `cv2.matchTemplate`. Без шаблонов
live-режим не найдёт героев, но `--mock` работает.

## Как добавить шаблон

1. Запустите игру в borderless/windowed.
2. Снимите фрагмент верхней панели с одним героем:

   ```sh
   python3 agent/capture_templates.py --name haze --x 300 --y 20 --w 90 --h 90 --manifest --hero haze
   ```

   Координаты `x/y/w/h` — относительно левого верхнего угла монитора.
3. Повторите для остальных героев. Имя файла и `hero` в manifest должны
   совпадать с `id` из `data/heroes.json` (например `haze`, `grey_talon`,
   `lady_geist`, `mo_krill`, `doorman`).
4. Проверьте:

   ```sh
   python3 agent/capture.py --once
   ```

## Калибровка ROI

Скопируйте `agent/roi.example.json` в `agent/roi.json` и подгоните нормализованные
координаты областей:

- `scoreboard` — область Tab-скорборда;
- `topbar` — верхняя панель с иконками героев;
- `hud` — нижняя панель с вашим героем/предметами.

Формат: `[x, y, w, h]`, где значения от 0 до 1.

## Ограничения

- скины, цветовые режимы и смена разрешения ломают шаблоны;
- верхняя панель содержит все 12 героев; агент не всегда знает, кто враг;
- Tab-скорборд надёжнее, но требует, чтобы пользователь его открыл (или
  эмуляции ввода, что в прототипе не делается).
