Захват экрана

Агент agent/capture.py читает скриншот, OCR/шаблоны ищет героев, затем публикует состояние. Веб-интерфейс может забрать его через /state.json.

Как это работает

  1. Захват: DXGI / Windows.Graphics.Capture / mss, borderless, кроп HUD.
  2. Детекция: OCR имён + template matching портретов; confidence threshold.
  3. Состояние: мой герой, 6 противников, время, предметы; JSON в state.json.
  4. Рекомендации: этот же движок в браузере; агент не читает память игры.

Запуск: python3 agent/serve.py, затем python3 agent/capture.py --mock во втором терминале. В песочнице агент не запущен — это нормально.
