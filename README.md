# Counter Items

Контр-предметы для **Dota 2** в Lua-окружении **Umbrella**. Скрипт анализирует способности и предметы врагов, учитывает роль и уже имеющуюся защиту и показывает список предметов, которые могут помочь в матче.

Скрипт только читает состояние игры и показывает подсказки: игровые команды и покупку предметов он не выполняет.

## Возможности

- Учитывает магический урон, контроль, невидимость, уклонение, лечение, иллюзии, пассивные способности, физический урон и другие угрозы.
- Указывает, против каких героев полезен совет; если угроза связана с предметом врага, показывает его значок.
- Учитывает способности и предметы своего героя, а также некоторые командные предметы союзников.
- Подбирает рекомендации с учётом роли, атрибута и типа атаки героя. Статистика покупок героя может уточнять пригодность предмета.
- Панель можно перемещать мышью при открытом меню. Настройки положения сохраняются.
- Интерфейс автоматически переключается между русским и английским в зависимости от языка Umbrella.

Советы основаны на эвристиках и игровых данных; это подсказки, а не гарантия оптимальной сборки.

## Требования

- Dota 2 и Umbrella с UC.Zone API v2 и Lua 5.4.
- Lua-окружение Umbrella с `require`, `assets.JSON`, файловым доступом и API игры, используемыми скриптом.
- [Справочник UC.Zone API v2](https://github.com/Nerve11/uczone-docs-UmbrellaDota2/blob/main/DocumentationUCZONE.md).
- Для статистики пригодности предметов — доступ к сети и OpenDota. Без сети скрипт продолжает работать, используя запасную оценку по атрибуту героя.

## Установка

1. Поместите `counter-item.lua` в `%cheat_dir%/scripts/` — каталог скриптов Umbrella.
2. Скопируйте каталог `ulib/` в `%cheat_dir%/`, сохранив его имя и структуру файлов.
3. Перезагрузите скрипт штатным способом Umbrella.

Не переносите отдельные модули `ulib` в разные каталоги: скрипт подключает их через `require("ulib.<module>")`.

## Настройки

Откройте меню Umbrella: **General → Main → Counter Items**. Названия пунктов будут на русском или английском в зависимости от языка чита.

- **Включить / Enable** — включает анализ и панель.
- **Моя роль / My role** — `Авто / Auto`, `Кор / Core` или `Поддержка / Support`. В автоматическом режиме скрипт использует выбранную роль поиска матча; если она неоднозначна, после 3:00 ориентируется на нетворс. До этого момента по умолчанию выбирается кор.
- **Показывать / Show** — панель всегда, при открытой лавке, при открытой лавке или смерти героя либо только с открытым меню. При открытом меню панель также можно перемещать.
- **Предметов в списке / Items in the list** — число карточек, от 3 до 8.
- **Предпросмотр / Preview** — пример панели вне матча. Включите его и откройте меню, чтобы посмотреть оформление и перетащить окно.

## Статистика OpenDota

Для героя запрашивается агрегированная частота покупок предметов по матчам OpenDota за последние 180 дней. Результат кэшируется на неделю; если по герою доступно меньше 30 матчей, используется запасная оценка по атрибуту. При ошибке сети текущий список советов не требует OpenDota.

Запрос содержит идентификатор героя и фиксированный список предметов для расчёта статистики; данные текущей игры и идентификатор игрока для этой функции не отправляются.

## Разработка и тесты

Чистые функции расчёта рекомендаций вынесены в `ulib/recommendations.lua`, а классификация жёсткого контроля и оценка физического DPS — в `ulib/threats.lua`. Автономные тесты проверяют оценки, контроль и урон, таймер, ошибки сохранения и восстановление из резервной копии, гонки и коллизии HTTP-кэша, повторную загрузку иконок, а также загрузку скрипта и выдачу рекомендаций на тестовом игровом состоянии.

GitHub Actions автоматически запускает тесты и проверку синтаксиса Lua при каждом push и pull request.

Запуск из корня репозитория в Lua 5.4:

```sh
lua tests/run.lua
```
